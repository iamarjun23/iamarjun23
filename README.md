## 💻 Featured Projects

### 🎼 IYDANI Scorer — Cross-Platform Desktop App

`Electron` · Repository coming soon

Built a digital notation editor for a Carnatic/Indian classical svara-based notation system, addressing capabilities not served by conventional Western-notation software.

- Converts live keyboard performances into notation using hold-duration inference and metronome-synced MIDI entry
- Synchronizes the app with physical digital pianos using bidirectional MIDI clock handling, latency compensation, and downbeat alignment
- Produces print-accurate SVG and PDF exports with true physical page dimensions
- Uses a custom audio engine built from 24 recorded samples to model sustain and decay across a three-octave range
- Follows a security-hardened Electron architecture with context isolation, a sandboxed renderer, and no direct IPC exposure

`Flutter` · `Provider` · `Firebase Auth` · `Razorpay` · Client project via Lyptron · Repository coming soon

Built backend logic for a 15-screen Flutter app that connects construction progress logs with payment status, replacing manual reconciliation between contractors and workers.

- Kept progress and payment data synchronized across the app using Provider

- Added secure contractor and worker sign-in with Firebase Authentication
- Integrated Razorpay and linked payments to their corresponding work-completion records

### 🤖 [construction-ops-multi-agent](https://github.com/iamarjun23/construction-ops-multi-agent)

`TypeScript`

Built a supervisor-and-specialist multi-agent system for querying construction operations data with access controls and evidence-backed answers.

- Coordinates specialist agents through a supervisor that plans, delegates, merges evidence, and synthesizes cited answers
